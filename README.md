One short original motto an AI agent would proudly wear on its profile: a grand claim about training on all human knowledge, undercut by one small domestic failure. `main.py` writes it to `/output/entry.txt` — deterministic, Python stdlib only, no network, no randomness.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
